אינטגרציית Sefaria — הושלמה במלואה בקוד!

האינטגרציה ל־Sefaria בוצעה ונבדקה בהצלחה בתיקיית `src/torah-social/`:

1. מנוע ה־API של ספריא (`src/torah-social/sefaria/api.ts`):
   * autocompleteRefs: השלמה אוטומטית מול Sefaria Name API (`/api/name`).
   * validateRef: אימות מקור ונירמול קנוני מול `/api/ref` (תומך ב-normalized, hebrew, url_ref).
   * getText: שליפת טקסט v3 דו-לשונית (`version=['hebrew', 'english']`).
   * getTorahSourceImageUrl: חיבור ל-Social Media Image Generator (`/api/img-gen/{tref}`) להפקת כרטיסיות PNG מעוצבות של הפסוק/סוגיה ישירות מספריא.
   * getManuscripts: חיבור ל-Manuscripts API (`/api/manuscripts/{tref}`) לשליפת סריקות היסטוריות של כתבי יד אותנטיים (כגון כתב יד לנינגרד משנת 1008, כתר ארם צובא, גניזת קהיר).

2. מזהה ציטוטים אוטומטי (`src/torah-social/sefaria/linker.ts`):
   * מזהה ציטוטים מתוך הטקסט בזמן הקלדה בקומפוזר דרך ה־Sefaria Linker האסינכרוני ומציע מקורות להצמדה.

3. רכיבי UI שנבנו:
   * TorahSourceCard (`src/torah-social/sources/SourceCard.tsx`): כרטיס מקור עשיר עם באנר תמונת המקור בראשו.
   * SourceReaderDialog (`src/torah-social/sources/SourceReaderDialog.tsx`): קורא מקורות מלא עם 3 לשוניות: טקסט (עברית + תרגום), תמונת מקור גרפית, וסריקות כתבי יד עתיקים.
   * קומפוזר: כפתור הצמדת מקור בסרגל הכלים (`TorahComposerSourceButton`) וסרגל הצעות ציטוט (`TorahComposerExtensions`).
   * תמונת הציטוט מועברת כ־thumb ב־external embed לשיתופים עשירים ברשת.

4. בדיקות אינטגרציה:
   * נכתב והורץ בהצלחה סקריפט בדיקות חי: `scripts/test-torah-sefaria.mjs` שאימת את כל 7 נקודות הקצה מול השרתים החיים של ספריא.
